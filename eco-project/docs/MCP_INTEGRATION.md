# Интеграция с MCP сервером

## Как MCP помогает экономить токены

1. **Context caching** - документация кешируется
2. **File references** - вместо кода указываем пути
3. **Tool use** - MCP читает файлы, не переписывает

## Команды для MCP

```
# Показать структуру проекта
@read_project_structure

# Показать все сигналы EventBus
@read_file docs/ARCHITECTURE.md

# Проверить консистентность
@search_in_project "EventBus.emit"
```

## Правила использования MCP с Gemini

1. Всегда просить MCP открыть ARCHITECTURE.md перед ответом
2. Использовать MCP для проверки, что сигнал уже не существует
3. MCP читает большие файлы вместо того чтобы AI их переписывала
